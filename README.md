# Prism — AI Video Studio & Telegram Mini App

Студия генерации видео на базе искусственного интеллекта: Telegram-бот и Telegram Mini App с поддержкой тем (light/dark), SQLite для хранения задач/тарифов/баланса, готовым MP4-видеоплеером, скачиванием и интеграцией с нейросетями.

---

## 🚀 Возможности проекта

1. **Создание видео прямо в Telegram-боте:**
   - Пользователь может просто отправить текстовое описание сцены боту (или команду `/generate <текст>`).
   - Бот генерирует MP4-видеоролик и присылает готовый файл прямо в диалог через Telegram `sendVideo` с кнопками повтора, баланса и перехода в Mini App.
   - Команды бота: `/start`, `/generate`, `/balance`, `/plans`, `/myvideos`, `/help`.

2. **Web-студия (Telegram Mini App):**
   - Настройка соотношения сторон: **16:9** (горизонтальное), **9:16** (вертикальное для Shorts/Reels/Stories), **1:1** (квадрат).
   - Настройка длительности: **4 сек** и **8 сек**.
   - Настройка качества: **480p** и **720p**.
   - Быстрые подсказки-чипы для вдохновения.
   - Интерактивный видеоплеер с кнопками:
     - ⬇️ **Скачать MP4**
     - 🔗 **Скопировать ссылку**
     - 🚀 **Поделиться в Telegram**
     - 🔄 **Ремикс / повторить промпт**
   - Telegram WebApp SDK: тактильная отдача (Haptic Feedback), синхронизация темы, авто-раскрытие (`expand`).

3. **Гибридный движок генерации видео:**
   - **Из коробки (Zero Config):** Работает сразу без платных ключей! Нейросеть генерирует кадры сцены высокого разрешения, а FFmpeg производит кинематографическое сведение с плавным движением камеры (эффект Ken Burns) в оптимизированный H.264 MP4.
   - **Продвинутый режим (Pollinations Video API):** При указании `POLLINATIONS_API_KEY` в `.env` проект использует diffusion-модели видеогенерации (`google/veo-3.1-fast`, `bytedance/seedance-1-pro-fast`, `alibaba/wan-2.6`).
   - Автоматический fallback: если у внешней видеомодели исчерпана квота или возникла задержка, генератор мгновенно выдаст кинематографичное видео вместо ошибки.

4. **Единая база данных SQLite (`prism.sqlite`):**
   - Единый аккаунт и баланс для Telegram-бота и Web-приложения.
   - Локальное сохранение сгенерированных роликов в `storage/videos/` для постоянного быстрого доступа и скачивания.
   - Защита от списания: при сбое генерации кристаллы автоматически возвращаются на баланс.
   - Демо-пополнение кристаллов в один клик.

## 🛠 Быстрый старт

Требуется **Node.js 20+**.

```sh
# 1. Установка зависимостей
npm install

# 2. Сборка фронтенда
npm run build

# 3. Запуск веб-сервера и API (в первом терминале)
npm run dev

# 4. Запуск Telegram-бота (во втором терминале)
npm run bot
```

- **Mini App (Frontend):** `http://localhost:5173`
- **Express API & Видео:** `http://localhost:3001`
- **Файлы видео:** `http://localhost:3001/videos/<id>.mp4`

---

## ⚙️ Настройка `.env`

Файл `.env` содержит следующие параметры:

```env
# Токен бота из @BotFather
TELEGRAM_BOT_TOKEN=ваш_токен_бота

# HTTPS адрес для кнопки Mini App (например, ngrok адрес на порт 5173)
MINI_APP_URL=https://ваш-ngrok-адрес.ngrok-free.dev

# Порт Express API
API_PORT=3001

# (Опционально) Ключ Pollinations для видео-моделей Veo / Seedance
POLLINATIONS_API_KEY=
POLLINATIONS_VIDEO_MODEL=google/veo-3.1-fast

# Путь к SQLite базе
DATABASE_PATH=prism.sqlite
```

---

## 📱 Подключение к Telegram

1. Откройте `@BotFather` в Telegram.
2. Перейдите в **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Вставьте ваш `MINI_APP_URL` (HTTPS URL из ngrok или хостинга, направленный на порт 5173).
4. Запустите бота командой `npm run bot` — теперь пользователи могут как нажимать кнопку меню для открытия студии, так и отправлять текст боту напрямую в чат для создания видео!
